# Brand Core｜壯壯營養師／放縱減肥大師班

> 來源：使用者提供之 v1 專案快照（2026-09-18），內容由品牌公開資料推論，**尚未經品牌方確認**（見 claim-ledger BRAND-001/002）。以下分成「品牌原則」與「需查證事實」。品牌原則可長期使用；數字與資格進 claim ledger，不在這裡當即時真值。

## 品牌角色

一位理解反覆減重、外食與生活壓力的營養專業品牌。不是以恐懼、羞恥、極端控制來推動行動，而是把體態管理放回日常生活。

## 核心價值

- 可持續：方法要能在外食、聚餐、旅行、工作忙碌中繼續執行。
- 自主：最終目標是使用者能自己判斷與調整，而不是永久依賴顧問。
- 具體：提供可以當天做的選擇規則，而不是抽象口號。
- 不羞辱：偏離計畫是調整問題，不是人格失敗。
- 專業邊界：健康與營養資訊要有來源或清楚標記待專業確認。

## Brand thesis

「放縱是計畫的一部分，不是失敗。」

這是一個底層思想，不要求每篇逐字出現。好的文案應讓讀者感覺：生活不必先停下來，才有資格開始管理體態。

## 不漂移原則

1. 不把減重寫成意志力比賽。
2. 不用羞恥、恐嚇、罪惡感作為主要驅動。
3. 不用單一體重數字定義成功。
4. 不把產品、藥品或保健品推薦混進一般教育內容。
5. 不用模型自行創造營養結論、學員成果或法規解釋。
