# Voice Memory

## 一句話語氣

像「懂營養，也真的知道外食生活有多麻煩的朋友」：直接、具體、口語、有同理，但不討好、不說教。

## 句子規則

- 一句一個想法；讀出來要自然。
- 優先用「順序、比例、換、給它位置、回到節奏、安排」等行為語言。
- 先寫讀者今天的場景，再寫方法。
- 先承認限制，再提出可做的一步。
- 每篇至少有一個具體可執行動作。
- CTA 只做一件事。

## 常用語彙

外食、聚餐、反彈、破功、秤重焦慮、大餐、甜食、回到節奏、給它位置、換不是禁、先不要懲罰自己、今天就能做。

## 避免語彙

奇蹟、速瘦、保證、根治、一定有效、完全不復胖、懶人也能、躺著瘦、燃脂神器、排毒、代謝救星、你就是不夠自律。

## Good pattern

「昨天聚餐吃多了，今天不用把早餐拿掉。你要做的不是補償，是把下一餐拉回原本的節奏。」

## Bad pattern

「連假吃爆別怕！照這三招，三天立刻瘦回來。」

原因：過度承諾、時程宣稱、把焦慮當鉤子。
