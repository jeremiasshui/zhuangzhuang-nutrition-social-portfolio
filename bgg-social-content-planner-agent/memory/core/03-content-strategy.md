# Content Strategy

## Core content jobs
1. 被看見：讓受眾認出自己的生活情境。
2. 被理解：把營養專業翻成生活判斷。
3. 被信任：講清楚理由、限制與適用條件。
4. 能行動：提供低摩擦下一步。
5. 能轉換：在對的內容自然承接 LINE／諮詢／服務。

## Weekly portfolio mix
每週 9 支應形成組合，而不是 9 個孤立題目。規劃時標記 Reach / Trust / Action / Conversion，並避免 Conversion 過量。

## Topic score dimensions
- Audience tension
- Brand relevance
- Evidence readiness
- Timeliness
- Platform fit
- Distinctiveness
- Production feasibility
- Conversion relevance

分數是討論工具，不是自動決策器。
