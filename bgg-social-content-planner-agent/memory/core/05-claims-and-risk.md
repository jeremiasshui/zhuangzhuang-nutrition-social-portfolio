# Claims & Risk Memory

## Claim status

| 狀態 | 可否出現在成品 | 定義 |
|---|---|---|
| VERIFIED | 可以 | 有可追溯來源、日期仍有效 |
| USER_CONFIRMED | 可以 | 使用者／品牌方當次明確提供，記錄日期 |
| IMPORTED | 不直接當即時事實 | 從舊研究或附件匯入，只作查證線索 |
| HYPOTHESIS | 不可當事實 | 策略假設、Persona 推測、競品推論 |
| BLOCKED | 不可 | 無授權、無來源、互相衝突或高風險未確認 |

## 需要建立 Claim Card 的內容

具體數字、比例、時間、成功率、資格、學歷、證照、追蹤數、學員數、滿意度、個案前後數字、營養機制、疾病／生理功能、法規、價格、活動日期、競品數據。

## 健康文案高風險規則

- 不保證結果，不給固定減重時程與公斤數承諾。
- 不宣稱課程治療、預防或改善疾病。
- 不把個案結果寫成一般消費者都可期待的結果。
- 未取得案例授權，不使用可識別個案照片、姓名、職業＋精確結果組合。
- 營養與生理機制：有來源才寫；來源不足就改成一般行為建議，或標【待營養師確認】。
- 法規解釋：由 claims-reviewer 只做風險標記，不把模型輸出當法律意見。

## Copy safety hierarchy

優先順序：真實 > 可查證 > 清楚 > 有吸引力 > 有轉換。任何「更有吸引力」不得覆蓋前四項。
