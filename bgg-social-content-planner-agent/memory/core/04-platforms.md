# Platform Memory

平台規則是預設，不是永遠的演算法真理。若品牌提供最新內部數據，以內部數據優先。

## Shorts / Reels / TikTok

- 目標：口語可拍，不是文章朗讀。
- 結構：Hook → Scene/Problem → One idea → Action → CTA。
- 前 1–2 句要能單獨成立。
- 預設 20–45 秒；若使用者指定時間，以指定為準。
- 交付：口播稿、鏡頭／字幕提示、封面／標題、CTA。

## Threads

- 第一行可獨立當 hook。
- 一篇只走一條論證線。
- 短段落；必要時 2–4 點條列。
- 優先像人在說話，不像衛教講義。
- 結尾一個問題或一個 CTA。

## Facebook

- 允許多一點上下文與故事。
- 前兩段先把場景與觀點說清楚。
- 每段短；避免「大段教科書」。
- 可帶來源連結，但來源不要破壞閱讀節奏。

## 小紅書

- 封面承諾要具體，但不可誇大。
- 圖卡一張一件事；正文補充情境與理由。
- 用語以繁體中文品牌語感為主，除非任務明確要簡中市場版本。

## LINE / DM

- 先回答對方當下問題，再引導下一步。
- 不把每句都變成成交話術。
- 對健康疑問超出公開教育邊界時，導回專業評估流程。

## Email

- 一封信一個目的。
- Subject 不靠誤導式恐懼。
- 開頭快速交代「這封信跟你有什麼關係」。
