# Audience Memory｜Persona + JTBD

Persona 是寫作代理，不是真人統計。每篇選 1 個 Primary Persona；必要時選 1 個 Secondary Persona。

## P1｜甜食環境工作者
- 情境：工作與甜食不可分離，過去用「完全禁止」失敗。
- JTBD：想管理體態，但不想把工作與生活切掉。
- 停留點：「甜食有位置」「換不是禁」。
- 滑走點：「戒糖」「永遠不要碰」。

## P2｜高壓上班族
- 情境：工作壓力、聚餐、晚睡；懂很多道理但執行崩掉。
- JTBD：希望偏離後能快速回到節奏，而不是重開人生。
- 停留點：反直覺原因 + 下一步。
- 滑走點：只給菜單，不說情境。

## P3｜秤重焦慮者
- 情境：頻繁量體重、對短期波動高度敏感。
- JTBD：想知道什麼變化需要調整、什麼不用反應。
- 停留點：判斷規則、觀察週期（若涉及時程需查證）。
- 滑走點：更多數字控制。

## P4｜家庭／照顧型使用者
- 情境：沒有時間為自己另做一套餐。
- JTBD：同一個家庭生活裡也能執行。
- 停留點：不用額外買、秤、煮。
- 滑走點：複雜 preparation。

## P5｜年輕短影音使用者
- 情境：注意力短、預算有限、先想拿免費方法。
- JTBD：三秒知道「跟我有什麼關係」，30 秒拿到一個做法。
- 停留點：反差、場景、簡單方法。
- 滑走點：長篇理論。

## P6｜應酬／業務型
- 情境：大餐是工作的一部分。
- JTBD：不退出社交，也能做選擇。
- 停留點：順序、比例、安排。
- 滑走點：禁止聚餐、強制運動。

## P7｜快速結果期待者
- 情境：想快、容易被速效內容吸引。
- JTBD：要明確下一步與真實預期。
- 停留點：簡單可見的行動。
- 風險：不要為留住他而承諾速效。

## P8｜理性／質疑型
- 情境：熟悉熱量、機制、科學術語，會追問證據。
- JTBD：需要知道這套方法與既有科學觀念如何相容。
- 停留點：承認邊界、引用來源、區分模型與個體差異。
- 滑走點：只有 slogan 沒有理由。

## 選 Persona 規則

不是「每篇讓八個人都喜歡」。先選一個最重要的人，讓文案對他夠具體；其他 persona 只用來檢查是否產生不必要的誤解。
