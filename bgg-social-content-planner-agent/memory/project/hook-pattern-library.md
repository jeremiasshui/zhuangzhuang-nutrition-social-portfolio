# Hook Pattern Library

記錄 hook 的功能與適用條件，而不是爆款句型收藏。

| Pattern | Audience state | Example structure | Risk | Evidence from own results |
|---|---|---|---|---|
| Recognition scene | 已有痛點但未命名 | 「你是不是每次___之後，就會___？」 | 太泛 | pending |
| Counter-intuitive | 有既定觀念 | 「真正讓你卡住的，不一定是___。」 | 過度反轉 | pending |
| Decision shortcut | 想知道怎麼做 | 「遇到___，先看這兩件事。」 | 過度簡化 | pending |
