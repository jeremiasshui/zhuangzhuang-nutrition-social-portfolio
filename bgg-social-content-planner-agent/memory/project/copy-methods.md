# Copy Methods Library

方法是「選擇器」，不是每篇都硬套。

## 1. Scene → Friction → Reframe → Action
適合：日常情境、Threads、短影音。  
先給看得見的場景，再指出卡點，換一個理解框架，最後只給一個可做行動。

## 2. Contrarian hook → Reason → Practical rule
適合：迷思、理性 Persona。  
反直覺句必須有可查證理由；不能為了 hook 捏造機制。

## 3. Permission → Boundary → Plan
適合：節慶、聚餐、偏離後自責。  
先解除不必要罪惡感，再給界線與下一餐／下一步安排。

## 4. Before → Turning point → Now → Lesson
適合：案例與品牌故事。  
只有在授權與 claim 可用時才用案例。不要把單一結果寫成普遍承諾。

## 5. JTBD copy
適合：服務介紹、landing page。  
寫「使用者在什麼情境想完成什麼進步」，而不是堆產品 features。

## 6. Tang-method subset（由 v1 研究整理）

可優先借用：對準 TA、對焦動機／心機／時機、開場有吸力、短句／畫面句／轉換句、首尾呼應、末語先寫、三安（安心／安慰／安排）、故事要有轉折與畫面。

完整來源見 `references/tang-copy-method.md`。只借結構與方法，不仿寫他人的特定句子。

## 7. SPIN／FABE（轉換型內容）
適合：board 裡的 Conversion 內容、FB 長文、LINE 導流前一步。
SPIN：情境 → 問題 → 影響 → 解決後的好處；S 與 P 直接用 demand-path map 的場景與問題原句。
FABE 的 Evidence 必須來自 claim ledger 的 VERIFIED／USER_CONFIRMED；學員案例（CASE-001）不可當證據。
同一套也是審稿標準，清單見 `references/landing-page-aiseo-method.md`。

## Framework selection rule

先選「讀者要完成的任務」，再選 framework。不要先決定 AIDA/PAS 再硬塞內容。
