# Memory 編輯規則

這個子樹不是一般筆記，而是專案的長期狀態。

- `core/`：只放 3 個月以上仍成立的品牌原則、產品邏輯、語氣與禁止事項。變更前必須在 `working/decision-log.md` 留理由。
- `project/`：可隨策略與產品更新。事實要帶來源、日期、狀態。
- `working/`：可以自由覆寫；每個任務完成後清理或歸檔。
- `learning/`：必須附樣本量／日期／平台／指標；不得把單一爆文當規則。
- 不在 memory 儲存個資、密碼、token、病歷、未授權個案細節。
- 遇到互相衝突的資訊，不直接覆蓋；同時保留兩筆並在 `working/decision-log.md` 標成 `CONFLICT`。
