# START HERE｜應徵社群內容企劃版

## 這套作品要證明什麼？

不是證明你會 Claude Code，而是證明你能把「社群內容企劃」做成一個有研究、有判斷、有交接、有數據回饋的循環。

## 建議第一次操作

在專案根目錄啟動 Claude Code，然後輸入：

```text
先讀 CLAUDE.md、docs/JD-MAPPING.md、docs/RUNBOOK.md 與 memory/00_INDEX.md。
這是一份應徵社群內容企劃的 portfolio workflow。
先執行 /audit-memory，不要先大量產稿。
接著告訴我：
1. 哪些品牌資訊已確認；
2. 哪些資料只是 seed，需要重新查證；
3. 建議本週研究問題；
4. 完成一份 9 支短影音的 content board 前，還缺哪些證據。
```

## 面試 Demo 最佳順序

不要從「這是我的 AI agent」開始。用一個真實題目，例如「聚餐後體重增加，要不要隔天少吃？」：

1. `/research-radar`：展示受眾語言、內容趨勢、營養查證需求。
2. `/plan-9-videos`：展示不是想到什麼寫什麼，而是有內容組合與目的。
3. `/write-script`：展示一份可以直接給拍攝者的腳本。
4. `/repurpose-content`：展示同一觀點如何變成 Threads、FB、小紅書、Shorts title。
5. `/handoff-qa`：展示你理解剪輯夥伴需要什麼，不是只交一段文字。
6. `/review-performance`：用 mock data 展示如何從數據得到「下一個測試」，而不是只報數字。
