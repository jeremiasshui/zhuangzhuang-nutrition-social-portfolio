## 二、他提出的具體手法

編號依「下筆前 → 標題 → 開場 → 結構 → 收尾 → 行動引導 → 文型分類 → 合規」排列。每條：名稱（他的用詞）／一句解釋／他給的例子。

### A. 下筆前

**1. 3W1H精準切入策略單**
- 解釋：動筆前先填一張策略單，把商品的 3W1H 想清楚再寫。課程原句「下筆前的商品3W1H精準切入策略單+現寫現改」；2015 課綱第一堂為「3W1H思考與文案寫作三項基本功」。
- 例子：未取得（課程頁只列單元名）。
- 出處：https://tangcd2002.pixnet.net/blog/posts/8229692668 ；https://www.bcccourse.com/CoursePage.aspx?cid=20150110015

**2. 對準TA—性別、年齡、階層**
- 解釋：先鎖定受眾的性別、年齡、階層，「找到傳達的準確受眾」，讓對方一看就知道在跟自己說話。
- 例子：伊莎貝爾喜餅鎖定「OL受氣包族」，文案「辭職反正也有老公養」「結婚，其實還不錯」。
- 出處：https://copywriter-study.tw/cht/index.php?code=list&flag=detail&ids=45&article_id=197 （刊於他官網「唐崇達文案教室」；頁面未另署名，視為本人教材）

**3. 對焦三機—動機、心機、時機**
- 解釋：動機＝對方想扮演什麼角色；心機＝沒說出口的真正渴望（他舉減肥課程背後其實是想選美）；時機＝製造購買的時點。
- 例子：溫泉業者把夏天也變成溫泉季，加入冰品、海鮮，讓「夏天泡湯消暑」成立。
- 出處：同上。文章標題說「三個文案法則」，抓到的內文只有這兩條，第三條：**未取得**。

**4. 準心、用心、人心**
- 解釋：「文案不是叫賣，有準心、有用心，才能打動人心」。準心＝點出店家賣什麼、也打中核心買家；用心＝先替客人想。
- 例子（逐字）：「有溫度的文案，不是等客人想買才跟他講，而是他還沒進門，就覺得你在為他想」；「文案不是要花大錢而是要走在別人之前」。文中案例是媽媽晚禮服店的燈箱文案。
- 出處：https://tangcd2002.pixnet.net/blog/posts/8227645702

**5. 照片能勾引，文案有導引**
- 解釋：社群內容用圖片抓眼、用文字帶方向，兩者分工。
- 例子：未取得。
- 出處：https://tangcd2002.pixnet.net/blog （部落格首頁摘要句）

### C. 開場

**10. 開場要有吸力，才能聚睛**
- 解釋：「開場的前三行，重要性就等同吸睛標題」，要「用設計性的講法，取代平鋪直敘」。
- 例子（逐字）：颱風天貼文開場「從北部過叫『斷頭颱』，從花蓮過叫『穿心颱』，從中南部稱『攔腰颱』」——他說一小時內兩百個讚。
- 出處：https://www.marketersgo.com/marketing-strategies-tactics/201607/facebookaddlike/ （文首標「本文作者為文案達人創意事務所執行長 唐崇達」）；同文轉載於 https://copywriter-study.tw/cht/index.php?code=list&flag=detail&ids=45&article_id=80

**11. 發文要有主題，才能對焦**
- 解釋：「寫文章要有作文題目，FB發文也是一樣。」主題可以顯性寫在最前面，或放進圖片。
- 例子：未取得。
- 出處：同 10。

**16. 品牌故事八個佈局**
- 解釋：品牌故事「並非只是詳述來龍去脈的流水帳」，要像「紙上單元劇」。八個佈局：引人入勝的故事主題／品牌源起和動心起念的開場／創業低點與高點的反差／由小做大的關鍵點／戲劇化的轉折／照映品牌精神的話語／品牌定位的自許／對未來的展望和承諾。
- 例子：未取得（文中無逐字範例）。

**17. 品牌劇場故事三要素與三大常見問題**
- 解釋：三要素「連結品牌本身、融入戲劇情節、符合故事結構」。三大問題：「把時間沿革與品牌願景的文字撰寫，就直接當做故事。沒頭沒尾沒情節的敘事，其實根本就稱不上故事」；故事與定位脫節；「缺乏『戲劇化』的轉折，缺少『畫面』語句」。並區分功能：「標題吸引注意、Slogan幫助記憶、故事促成回味與傳播」。
- 例子：未取得。
- 出處：https://tangcd2002.pixnet.net/blog/posts/8229045070

**18. 一頁式銷售頁基本構型**

### E. 溫度、啟發與收尾

**19. 字句要有溫度，才能交心**
- 解釋：多寫心情分享、勵志短句、正向思考或感人故事。
- 例子：未取得。
- 出處：同 10。

**20. 內容要有啟發，才能擴散**
- 解釋：寫實用知識、鼓舞語錄、解析文、探討文、成功啟示或方法文，讀者「深受啟發」才願意分享。
- 例子：未取得。
- 出處：同 10。

**21. 結語要有感言，才能回味**
- 解釋：兩個收尾技巧——「首尾呼應」或「末語先寫」（先寫好最後一句再回頭寫全文）。
- 例子：未取得。
- 出處：同 10。

**22. 三安文案：安心、安慰、安排**
- 解釋：危機時期（疫情）的三種寫法。安心＝「客人並非每天都想深居簡出，他也想要有個安心的去處」，把防護措施寫出來；安慰＝「易地而處的安慰是憂傷的良藥」；安排＝取消時不只說不辦了，而是承諾未來。
- 例子（逐字）：新北市觀旅局取消鐵道馬拉松：「今年，我們會晚點跑，但一定會跑。」；璞樹文旅「潔淨呼吸八步驟」系列。
- 出處：https://copywriter-study.tw/cht/index.php?code=list&flag=detail&ids=45&article_id=442

### H. 合規與不誇大

**30. 保健食品文案五大雷**
- 解釋：一、保健食品卻宣稱療效；二、「提出預防、改善、減輕等生理狀況字句」；三、沒有中藥成份卻寫出中藥效能；四、「生理功能與身體外觀誇張效能」；五、「魚目混珠使用衛福部食字號」。結論：「合乎法規與妥善轉換，仍可達成有效行銷」。
- 例子（逐字，他列的違規字）：「預防便秘、改善血濁、減輕過敏性皮膚病、防止貧血、治療失眠、解除肝毒、利尿、壯陽、強精」；「解酒、補腦、排毒、增強記憶力、豐胸、減肥、美白、增高、防止老化」。
- 出處：https://copywriter-study.tw/cht/index.php?code=list&flag=detail&ids=45&article_id=234

**31. 化妝品文案四大迷思（其中「神蹟」一條通用）**
- 解釋：迷思三「化妝品可講得像神蹟般靈驗」。
- 例子（逐字，禁用詞）：「立即見效、百分百無副作用、完全根治、不再復發」；迷思四誇大例「100%天然」。
- 出處：https://copywriter-study.tw/cht/index.php?code=list&flag=detail&ids=45&article_id=233

**32. 品牌避免失敗的「十個不要」（抓到五項）**
- 解釋：「不要樂觀認為所有人都會買你的東西」「不要把品牌預算花在不可能買你的消費者身上」「不要因為在熟悉領域成功，就推出跨界品牌延伸商品」「不要認為有打廣告就會成功」「不要以為品牌的巨大領先優勢會是永遠」。
- 例子（逐字）：「廣告是讓消費者認知品牌與產生好感的媒介，但不等於熱賣保證。」後五項：**未取得**。
- 出處：https://copywriter-study.tw/cht/index.php?code=list&flag=detail&ids=45&article_id=196

## 三、可直接套用在短影音腳本（15–60 秒口語）與 Threads 短文（300 字內）的手法

| 手法 | 套用方式 |
|---|---|
| 10. 開場要有吸力（前三行＝標題） | 短影音前 3 秒、Threads 第一行，就是他說的「前三行」。照「斷頭颱／穿心颱／攔腰颱」的做法：用一個自創的命名或分類法開場，不要用「今天來聊聊」。例：把外食族的三種吃法各取一個名字。 |
| 11. 發文要有主題 | 一支影片、一則短文只講一個題目，開頭就點題。Threads 可把題目當第一行。 |
| 12. 短句、畫面句、轉換句 | 口語腳本天然要短句；每段至少一個「看得見」的畫面句（便當盒、加班桌上的手搖）；結尾用轉換句把知識轉成「所以你可以…」。 |
| 2.＋3. 對準TA、對焦三機 | 腳本第一句就叫出受眾（「常加班的外食族」）；用「心機」找沒說出口的渴望（不是「瘦」，是「不用再對聚餐說不」）；用「時機」掛上節日、聚餐季。 |
| 4. 準心、用心 | 先替對方想：「他還沒進門，就覺得你在為他想」。短文開頭直接寫出對方今天會遇到的難處，而不是我們提供什麼。 |
| 19. 字句要有溫度 | 短文用第二人稱、口語，允許一句「我懂」。不寫成衛教條列。 |
| 20. 內容要有啟發 | 每則至少給一個可以立刻做的小方法（他的「方法文」「知識文」），這是被分享的原因。 |
| 21. 首尾呼應／末語先寫 | 寫腳本先寫最後一句，再回頭寫開頭讓它扣回去。60 秒影片最後一句 = 開頭命名的回收。 |
| 22. 三安（安心、安排） | 用「安排」的寫法處理假期、聚餐、破戒：不說「不能吃」，說「這餐照吃，明天這樣安排」。逐字範本「今年，我們會晚點跑，但一定會跑」的句式可改寫成減重情境。 |
| 26–29. 二十種文型 | 當作每週選題輪盤：提問文、發現文、經驗文、方法文、時事文、吃喝玩樂文最適合 Threads；證言文、好康文、推薦文要看第四節限制。 |
| 8. 金句吸單五傳（眉主副標） | 短影音字卡照「眉標—主標—副標」三層排：眉標點受眾、主標一句金句、副標補一個具體情境。 |
| 16.–17. 故事要有轉折與畫面 | 60 秒個案故事用「低點→轉折→現在」三拍，不寫流水帳；每拍配一個畫面句。 |
| 25. 文案對話術 | Threads 回覆留言時用「化解不同意見」「處理客戶抱怨」的態度：先接住再說明。 |
| 30.–31. 五大雷、神蹟禁語 | 寫完自檢：有沒有「改善、預防、減輕、立即見效、100%」這類字。 |

## 四、與品牌鐵則的相容性

品牌鐵則：不算熱量、不保證結果、不推產品、行動引導只有一個。

### 可以直接用
- 1、2、3、4、5（下筆前的受眾與動機分析）——與鐵則無衝突，反而幫助避開「算熱量」話題：對焦的是心機（不想再對聚餐說不），不是數字。
- 10、11、12、13、14、19、20、21、22（開場、句子、結構、溫度、啟發、收尾、三安）——純寫作技術，無風險。
- 16、17（故事佈局）——個案故事可用，但轉折不能寫成「用了 X 就瘦 Y 公斤」的結果保證（見下）。
- 26、27、29 文型中的情感文、感想文、時事文、發現文、喜悅文、提問文、趣味文、吃喝玩樂文、勵志文、啟示文、語錄文——都不涉及產品與結果。
- 30、31（五大雷、神蹟禁語）——與「不保證結果」同向，直接當自檢清單。
- 25 對話術——與「行動引導只有一個」不衝突，用在留言互動。

### 要調整後才能用
- 7、6 標題法、23 十八種誘因：他的誘因字裡「療」「健」「變」「神」「限」「贏」直接踩「不保證結果」與五大雷；「省」「情」「新」「快」「便」「享」「解」可用，但「解」不能寫成解決某生理問題。十二大／二十一式標題的內容未取得，實際使用前逐條檢查。
- 28 七大進階分享文中的「證言文」「推薦文」「好康文」：證言只能寫感受與行為改變（「這週聚餐我沒有焦慮」），不能寫體重數字或保證；推薦文不得指向產品；好康文只能是免費內容或單一行動。
- 18 一頁式銷售頁構型：「後場使用者證言」「商品櫥窗導引」兩段要拆掉或改寫；前場「版頭標題與定位」與中場「賣點」可保留，但賣點是方法不是產品。
- 8 金句吸單五傳：名稱裡的「吸單」是導購目的，只借用「眉主副標佈句」的排版邏輯，不把每張圖都導到下單。
- 24 文案贏客術六組關鍵：內容未取得；其中「讓買家想你就能找到你」（單一入口）與「行動引導只有一個」相容，其餘待內容取得後再判斷。
- 15 倒三角寫法：適合公告類，但短影音需要前三秒吸力，兩者衝突時以第 10 條為主。

### 不能用
- 「療」「健」二字誘因、任何「預防、改善、減輕、立即見效、完全根治」寫法——同時違反品牌「不保證結果」與他自己列的五大雷。
- 18 中「商品比較表」——比較表必然推產品。
- 任何把「熱量」當標題數字梗的下標法（他的標題法裡若含「數字標」，在本品牌不得用熱量數字）。
- 一則內容同時放「追蹤＋私訊＋報名」多個引導——與鐵則「行動引導只有一個」衝突；他的「六組關鍵」若要求多重觸點，只保留一個。
