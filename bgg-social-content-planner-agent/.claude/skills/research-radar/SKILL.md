---
name: research-radar
description: Build a weekly research radar from audience, trend, competitor/reference and evidence inputs.
---

1. Read current-week, audience memory, source registry and audience language bank.
2. Use audience-researcher for supplied comments/FAQs; use reference-researcher when fresh external research is available.
3. Separate source-backed signals from hypotheses.
3a. Build a demand path map (`templates/demand-path-map.md`, method in `references/demand-path-method.md`): 3–5 priority personas × 3–5 scenes → problem wording → brand behavior-level answer with claim ID → hook direction. Candidate topics come from this map.
4. Produce 15–20 candidate topics with source, audience tension, novelty, evidence readiness and risk.
5. Save to `memory/working/research-radar.md` and create a dated archive in `work/research/`.
