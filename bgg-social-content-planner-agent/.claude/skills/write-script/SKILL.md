name: write-script
description: Write one shoot-ready short-form video script from an approved content-board item.
---

1. Confirm approved topic brief and claim status.
2. If risk is high, call claims-reviewer before finalization.
3. Ask scriptwriter for 2 hook directions, then choose based on audience tension.
4. Draft Hook, Context, Body beats, Takeaway, CTA, On-screen text, Storyboard（分鏡表，見 templates/short-video-script.md）, Fact notes, Production notes.
5. Run copy-editor. Revise once if FIX.
6. Save approved asset in `output/` with source/claim references.
