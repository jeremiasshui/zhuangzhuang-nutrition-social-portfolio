# BGG Social Content Planner Agent

這是一套「社群內容企劃職務模擬＋實務工作台」，不是自動發文機器。

它把職缺中的六大工作內容拆成可執行、可查證、可回顧的流程：

1. 社群研究與選題
2. 每週約 9 支短影音規劃與腳本
3. 跨平台內容轉譯
4. 拍攝／剪輯交接與品質確認
5. 基本成效分析與下一輪優化
6. 內容資料庫、流程與主管回饋的持續累積

## Portfolio value

面試時重點不是展示「AI 幫我寫了很多文案」，而是展示：
- 我會定義受眾問題與內容目的。
- 我知道如何找證據與參考案例。
- 我能寫成可直接拍攝的腳本。
- 我知道同題材在不同平台不能直接複製。
- 我能把營養正確性、品牌語氣與製作品質拆成不同 QA。
- 我能從數據提出下一輪可驗證假設。
- 我能把主管修改逐步沉澱成可維護的品牌 memory。
