## JD 的六個問題 → 系統欄位

| JD 問題 | 系統在哪裡回答 |
|---|---|
| 這個內容想與哪一群人溝通？ | Primary Persona（demand path map、board 的 Audience） |
| 他們目前遇到什麼問題？ | 問題原句（audience-language-bank）、board 的 Tension |
| 什麼開場方式會讓人願意繼續看？ | Hook angle＋hook-pattern-library |
| 如何把營養知識說得清楚、自然又有吸引力？ | scriptwriter＋claim ledger（先正確再吸引） |
| 同一個主題如何轉化成適合不同平台的內容？ | platform-matrix |
| 發布後的數據，能帶給我們哪些下一步方向？ | performance-review 的 3 個可測試假設 |

## 面試時的核心敘事

「我沒有把 AI 當成自動文案機器。我把職缺拆成研究、策略、腳本、平台轉譯、製作交接、QA、成效回饋七個決策點；AI 負責加速蒐集、整理與產生候選方案，涉及營養正確性、品牌取捨與最終發布的地方仍保留人工確認。」

## 不要主打的內容

- 幾十個 agents 同時工作。
- 一次生成幾十篇文章。
- 100% 全自動發文。
- 「AI 保證爆款」。

這些都弱化職位真正需要的研究、判斷、協作與迭代能力。
