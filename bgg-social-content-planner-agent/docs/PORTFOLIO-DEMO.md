# Portfolio Demo｜建議你實際拿去面試的 8 頁內容

## P1｜問題定義
「社群企劃不是寫 9 支稿，而是建立一個能持續學習的內容循環。」

## P2｜Workflow Map
Research → Audience Insight → Topic Board → Script → Cross-platform → Production Handoff → QA → Performance → Learning

## P3｜Weekly Research Radar
展示 5–8 個受眾問題、真實語言、3–5 個參考案例，以及你為什麼不照抄。

## P4｜9-Video Content Board
每支顯示 audience / tension / purpose / hook / evidence / CTA / platform priority。

## P5｜一支完整 Script
讓主管看到可以直接拍，不是抽象文案。

## P6｜Cross-platform Matrix
同一主題展示 Threads、FB、小紅書、Reels/Shorts 的差異。

## P7｜Production QA
展示你會把 script 交接給影音夥伴，也會檢查字幕、原意、claim、CTA。

## P8｜Performance Learning
用示範資料回答：什麼有效？什麼還不能下結論？下一輪測什麼？

## 10 分鐘 Demo 原則

- Agent 架構只講 1 分鐘。
- 內容判斷與交付物講 7 分鐘。
- 數據與 learning loop 講 2 分鐘。

主管要看到的是你的企劃能力，而不是工具複雜度。
