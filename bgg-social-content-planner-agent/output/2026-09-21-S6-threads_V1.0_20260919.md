# Threads｜S6 你中秋最怕什麼？

## 1. 鎖定核心（不隨平台改）

- 核心觀點：中秋最怕的三種場合，你選一個。
- 三個選項：烤肉／月餅／親戚一直夾菜（與短影音版一致，留言才能合併統計）。
- Claim：無。只問不答，不給飲食建議。

## 2. 平台使用情境（platform-adapter）

| 項目 | Threads 版 | 短影音版（對照） |
|---|---|---|
| 使用情境 | 滑文字動態，看到有共鳴的就回覆；回覆本身就是內容，別人會看回覆區 | 滑影片，停留靠畫面和前 3 秒 |
| Hook | 第一行就是問題，單獨出現在動態也看得懂 | 翻字卡的動作＋口播 |
| 結構／篇幅 | 約 110 字；問題 → 三個選項各配一句場景 → 品牌一句 → 回覆指令 | 20 秒；問題 → 翻三張卡 → 說明為什麼問 → 留言 |
| CTA | 回覆一個數字＋一句場面 | 留言 1／2／3＋一句場面 |

## 3. Hook 選擇（兩個方向）

| 方向 | 句子 | 取捨 |
|---|---|---|
| A 問句型 | 「中秋連假，你最怕哪一個？」 | **採用**。Threads 第一行要能單獨成立，而且一看就知道要回什麼。 |
| B 觀點型 | 「中秋最難的不是吃，是那個場面。」 | 不採用。比較有個性，但讀者要讀到第三段才知道要回覆，互動門檻變高。 |

## 4. 貼文正文（直接複製發布）

中秋連假，你最怕哪一個？

1 烤肉
香腸、貢丸一盤一盤烤，停不下來

2 月餅
辦公室一盒、客戶一盒，回家又一盒

3 親戚一直幫你夾菜
碗還沒空，又滿了

每一個都不用躲。
但我想先知道，你卡在哪一個。

回覆一個數字，
再多講一句：你最怕的是哪個場面？

## 5. 改了什麼、為什麼

| 改動 | 原因 |
|---|---|
| 每個選項多一句場景 | 文字貼文沒有畫面，靠一句場景讓讀者「看到」自己；短影音用插畫就夠了。 |
| 拿掉「烤肉跟月餅這週的影片已經講過了」 | S3、S4 是短影音，Threads 上不一定有對應貼文；指向看不到的內容會讓人困惑。 |
| 加「每一個都不用躲」 | 回應 editorial ④（S6 品牌落款弱）：用本週 S3 已用過的許可語氣，讓人認得是壯壯。這句只是態度，不是飲食建議。短影音版要不要也加，仍待使用者決定。 |
| 「留言」改「回覆」 | Threads 介面用的字是「回覆」。 |
| 不用投票功能 | 投票只拿到數字，拿不到「最怕的場面」那句話；這支的目的之一是蒐集受眾用語（JD 一）。 |
