# 壯壯營養師｜社群內容企劃作品集

作者：水彥捷

這是應徵「社群內容企劃」職缺時做的作品集。我用 Claude Code 搭了兩套多代理工作流程，把社群內容企劃的日常工作拆成可以查證、可以回顧的步驟。重點不在 AI 寫了多少文案，而在流程怎麼設計、品質怎麼把關。

## 內容

### 1. `bgg-course-plan/`：研究與一週規劃

- `research.md`：品牌公開資料研究筆記
- `weekly-social-plan.md`：一週跨平台社群內容規劃（9 支短影音）

### 2. `bgg-social-content-planner-agent/`：內容企劃職務模擬工作台

把職缺的六項工作內容（研究選題、短影音腳本、跨平台轉譯、拍攝交接 QA、成效分析、品牌記憶累積）拆成代理與技能。從 `START-HERE.md` 開始看。

### 3. `bgg-social-agent/`：跨平台文案寫審迴圈

四個平台寫手（短影音、Threads、Facebook、小紅書）平行寫文案，五個審稿員（品牌、營養、證據、法規、受眾）分頭審。迴圈跑到驗收清單全部通過，或跑滿三回合為止。

- 需求與設計：`docs/PRD.md`、`docs/SDD.md`、`docs/adr/`（設計決策紀錄）
- 黃金樣本：`eval/`
- 自動檢查：`scripts/check_copy.py` 與 `tests/`
- 完整專案說明（單一 HTML）：`export/project-dossier.html`

## 刻意沒放進來的東西

- 營養原始資料（衛福部食品營養成分資料庫等，約 443MB）：檔案太大，請從官方來源重新下載。
- Python 虛擬環境與壓縮檔。
- 學員身體照片截圖：沒有取得授權。
