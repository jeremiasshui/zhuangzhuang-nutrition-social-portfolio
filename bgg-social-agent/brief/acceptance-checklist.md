# 驗收清單（審稿員逐條判定，寫手逐條自檢）

| 編號 | 條件 | 誰審 |
|---|---|---|
| C1 | 符合 `platform-formats.md` 該平台格式（段落、字數、附件項） | reviewer-brand |
| C2 | 開場一句有鉤子：反差、問題或具體場景 | reviewer-brand |
| C3 | `brand-rules.md` 全部通過，含三條硬性守門 | reviewer-brand |
| C4 | 每個份量、機制、時程敘述附【待營養師確認】；每個結果附「因人而異」 | reviewer-nutrition |
| C5 | 行動引導只有一個，且是留言關鍵字或 LINE | reviewer-brand |
| C6 | 核心訊息與 `weekly-social-plan.md` 同編號腳本一致；案例數字與 `research.md` 一致 | reviewer-nutrition |
| C7 | 營養敘述不與本機國健署、食藥署資料牴觸（`brief/sources.md`） | reviewer-evidence |
| C8 | 無療效宣稱、無結果保證、案例有揭露（`brief/ad-regulations.md`） | reviewer-legal |
| C9 | 人物模擬：八個人物過半留下，且至少一位做出目標行動（`brief/personas.md`） | reviewer-audience |

判定只有兩種：`PASS` 或 `FIX`。`FIX` 必須引用原句並給出改法。
迴圈結束條件：全部檔案九條皆 PASS，或已滿三回合。
