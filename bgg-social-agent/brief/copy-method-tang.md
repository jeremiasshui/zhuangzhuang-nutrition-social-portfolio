# 唐崇達文案手法（寫手必讀）

來源：`docs/research/tang-chongda-copy-method.md`，32 條手法、32 個一手來源。這裡只留寫手要用的，編號沿用研究筆記。

## 直接用（每支腳本至少用兩條，檔頭「文案手法」欄寫編號）
| 編號 | 手法 | 怎麼用在我們的腳本 |
|---|---|---|
| 10 | 開場要有吸力，前三行就是標題 | 前三秒用一個自創命名或分類開場，例如把外食族的三種吃法各取一個名字。他的例子：「斷頭颱／穿心颱／攔腰颱」 |
| 2、3 | 對準 TA、對焦三機（心機、時機、動機） | 第一句叫出人物；心機不是「瘦」，是「不用再對聚餐說不」；時機掛中秋 |
| 4 | 準心、用心 | 開頭先寫對方今天會遇到的難處，不寫我們提供什麼 |
| 12 | 短句、畫面句、轉換句 | 每段一個看得見的畫面（烤肉架、月餅盒、體重計）；結尾一句「所以你可以…」 |
| 19 | 字句要有溫度 | 第二人稱、口語、允許一句「我懂」；不寫成衛教條列 |
| 20 | 內容要有啟發 | 每支至少一個立刻能做的小方法 |
| 21 | 首尾呼應、末語先寫 | 先寫最後一句，再寫開場扣回去；60 秒影片最後一句回收開頭的命名 |
| 22 | 三安：安心、安排 | 破戒與假期用「安排」寫：「這餐照吃，明天這樣安排」。句式範本：「今年，我們會晚點跑，但一定會跑」 |
| 16、17 | 故事三拍：低點、轉折、現在 | S4 案例用；轉折寫行為與感受，不寫體重數字 |
| 8 | 眉標、主標、副標三層 | 短影音字卡：眉標點受眾、主標金句、副標具體情境 |
| 30、31 | 五大雷、神蹟禁語自檢 | 寫完檢查：改善、預防、減輕、立即見效、100% 都不能出現 |

## 要調整
- 誘因字：「省、情、新、快、便、享」可用；「療、健、變、神、限、贏」不用；「解」不能寫成解決生理問題。
- 證言文只寫感受與行為改變（「這週聚餐我沒有焦慮」），不寫數字不寫保證。
- 眉主副標只借排版，不把每張圖導到下單。
- 倒三角寫法與前三秒吸力衝突時，以吸力為主。

## 不能用
「療、健」二字；「預防、改善、減輕、立即見效、完全根治」；商品比較表；熱量當標題數字梗；一則內容放多個行動引導。
