# PRD｜社群內容代理迴圈

版本 1.0｜2026-09-18｜作者：水彥捷｜名詞依 `CONTEXT.md`

## 1. 背景
壯壯營養師團隊的「社群內容企劃」職缺要求每週規劃約九支短影音、跨平台改寫、與剪輯協作、整理成效。同一家公司的「線上課程產品企劃」職缺下週面試。作者要在一天內交出一份課程作業：一個有 AI agent、有 harness、有迴圈、有圖、附討論過程的系統，並且產出能直接用於面試的文案作品。

## 2. 問題
用單一 AI 一次寫 36 份文案，會有四個問題：寫錯營養敘述沒人抓、違反品牌語氣沒人抓、觸法沒人抓、受眾看不看沒人知道。作者是程式新手，需要一個「產出者與驗證者分開、驗證有紀錄、驗證器本身可以被量、人做最後決定」的系統，而不是更會寫的 AI。

## 3. 目標
| 編號 | 目標 | 怎麼驗證 |
|---|---|---|
| G1 | 36 份文案全部通過 CI 五項檢查 | GitHub Actions 綠燈 |
| G2 | 每份文案九條驗收清單有明確判定 | `reviews/` 每平台每回合五份審稿檔，各 9 列 |
| G3 | 每回合的討論可追溯：誰提意見、改了哪句、誰裁決 | `log/discussion.md` 能不看其他檔案讀懂 |
| G4 | 系統能重跑：在專案目錄執行 `/run-week` 就能再跑一次 | 作者親自跑一次 |
| G5 | 每句營養敘述可回到國健署或食藥署來源，或標明無來源 | `reviews/*/round-N-evidence.md` |
| G6 | 文案不含療效宣稱、結果保證、未揭露的薦證 | `reviews/*/round-N-legal.md` 高風險為 0 |
| G7 | 每份文案經過至少六個人物模擬閱讀，有留存與行動預測 | `reviews/*/round-N-audience.md` |
| G8 | 驗證器有成績單：黃金樣本命中率、一致性、推翻率 | `log/discussion.md` 指標表 |

## 4. 使用者
- **作者**：跑系統、讀討論記錄、抽查判定、做未收斂的決定、把成果帶去面試。
- **老師**：看作業文件（HTML），評的是流程與設計，不是文案。
- **面試官**：看文案與方法，評的是規劃能力與查證習慣。

## 5. 範圍
**做**：四平台文案、CI 檢查、五種審稿、三回合迴圈、黃金樣本、討論記錄、PRD／SDD／ADR／名詞表、Mermaid 架構圖、HTML 作業文件、GitHub 私人倉庫與 PR、同業結構範本、人物檔。
**不做**：發布到任何平台、抓 IG／TikTok 資料、跨廠商模型（GPT、DeepSeek）、自動合併、修改模型權重、剪輯、用真實數據校準人物（要等基準週）。

## 6. 限制
- 明天交件。
- Claude Max 方案，用量可承受三回合乘四寫手五審稿員。
- IG、TikTok 需登入，抓不到；同業研究只用抓得到的一手來源。
- 學員案例授權拿不到，S4 只用數字卡並標【授權待確認】。
- 所有營養具體敘述標【待營養師確認】，系統不自行決定營養學對錯。
- 壯壯自己的貼文曾寫熱量數字（2026-09-17 菜單貼文），「不放熱量數字」是本專案採用的假設，不是公司規定。

## 7. 成功條件（交件時逐項打勾）
- [ ] 倉庫在 GitHub，私人，含 CI workflow。
- [ ] 至少一回合完整跑完，四個平台各有 PR，CI 有執行紀錄。
- [ ] `log/discussion.md` 有至少一次裁決、一份指標表、一份未收斂或已收斂清單。
- [ ] 黃金樣本至少六份，審稿員跑過一次，命中率有數字。
- [ ] HTML 作業文件含：PRD、SDD 與圖、名詞表、ADR、代理定義、CI 結果、PR 連結、討論記錄、36 份文案附錄。
- [ ] 作者能用自己的話說出：問題是什麼、為什麼這樣設計、放棄了什麼、怎麼知道它有效。

## 8. 風險
| 風險 | 影響 | 對策 |
|---|---|---|
| 審稿員之間意見互相矛盾 | 寫手不知道聽誰的 | 總編裁決並記錄 |
| 三回合不收斂 | 沒有可交的文案 | 不合併，清單交人；未收斂本身是作業裡的有效結果 |
| 寫手學會「剛好過關」而不是寫好 | 驗收全過但文案很爛 | 黃金樣本放表面合規反例；人物模擬；人抽查 |
| 人物模擬與真實受眾不符 | 預測誤導改寫方向 | 標明為代理指標；基準週後用真實數據校準 |
| 代理讀錯檔案或路徑 | 產出跑到錯的地方 | 路徑固定寫在 CLAUDE.md，CI 檢查檔案數與位置 |
| 法規指引過時 | 法規審稿判錯 | 只引用研究員逐字抄錄的現行條文 |

## 9. 缺少的資訊（面試時要問公司的）
課程平台與影片數、完課率、LINE 每週加入數基準、拍攝資源與審核流程、小紅書是否經營、案例授權狀態、菜單型內容要不要寫熱量、營養師法第 13 條通訊執業報准狀況。
