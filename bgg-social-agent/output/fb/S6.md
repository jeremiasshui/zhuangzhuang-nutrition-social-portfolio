# S6｜連假後體重多兩公斤？八成是水，三天判斷法｜fb
回合：1
本輪修改：初稿
主要人物：P3
參考案例：許可框架金句
文案手法：待補

連假後站上體重計，多兩公斤。先不要慌。

這個時候最容易做錯事。有人直接跳過早餐，有人隔天水煮餐伺候。都是在懲罰身體。

先講事實。
三天烤肉月餅，鹽分、澱粉、水分會暫時留在身體裡。【待營養師確認】
多出來的這兩公斤，八成是水，不是脂肪。【待營養師確認】

放縱派的三天判斷法：
一、照常吃三餐，什麼都不改。
二、三天後再量。【待營養師確認】
三、看腰圍，不看體重。

三天後大部分的水會走掉。因人而異。
腰圍才是真的變化。體重會騙人，皮尺不會。【待營養師確認】

課程裡我們叫這個「卡關調整」。偏離不是失敗，是要學會怎麼回來。

放縱是計畫的一部分。連假吃多了，也是。

連假後想用這個方法的人，留言「三天」，我把判斷表私訊給你。
