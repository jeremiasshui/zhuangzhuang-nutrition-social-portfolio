# S2｜月餅一顆等於一餐？放縱派這樣吃｜fb

主要人物：P1
參考案例：待補

一顆蛋黃酥要跑五公里？不用，你只需要換一碗飯。

中秋前後，公司發、客戶送、親戚拿來。月餅一盒一盒進來，你看著它，心裡在算要怎麼還。

放縱派的做法不是禁，是換。

月餅就是那一餐的澱粉。【待營養師確認】
那一碗飯換成月餅，蛋白質和蔬菜照常配。【待營養師確認】

不同月餅怎麼安排比較順：
一天一顆，不要一次清一盒。【待營養師確認】
選小顆的，一口大小的蛋黃酥比整顆廣式月餅好安排。【待營養師確認】
配無糖茶，不要配含糖飲料。【待營養師確認】
晚餐要聚餐的那天，月餅排在早餐或午餐。【待營養師確認】

重點不在熱量，在它有位置。
有位置的甜食小確幸，就不算破功。

哪一種月餅最好安排？留言「月餅」，我一個一個回。
