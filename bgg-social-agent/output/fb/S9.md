# S9｜你中秋最怕的是什麼？留言決定我下週拍什麼｜fb

留言區決定我下週拍什麼。

中秋連假三天，烤肉、月餅、親戚聚餐一次到齊。每個人怕的東西不一樣，我想知道你怕哪一個。

一、烤肉。一路吃到收攤，隔天小腹先出來報到。
二、月餅。一盒一盒進來，不吃浪費，吃了自責。
三、親戚一直夾菜。說不要，他夾更多，最後餐餐吃超飽。

三個選一個，留言關鍵字就好：「烤肉」「月餅」「夾菜」。

留言最多的那一個，下週拍一支完整的。
每一則留言團隊都會逐一回覆，你怕的那件事，我們一起想辦法。

順便說一句：不管你選哪個，放縱都是計畫的一部分，不是失敗。連假放心過，我們連假後見。
