# S5｜熱量算得很準還是瘦不下來？問題不在算錯｜fb

主要人物：P8
參考案例：反直覺機制
文案手法：待補

你有熱量赤字，體重卻不動。問題不在你算錯。

很多人算得很認真。每一餐秤重、每一口記錄，App 說你今天吃得比消耗少。幾週過去，體重計一格都沒動。

然後你開始懷疑自己：是不是偷吃了？是不是算漏了？

不是。公式算不到三件事。

一、代謝。每個人的代謝不一樣，公式給的是平均值。【待營養師確認】
二、荷爾蒙。壓力荷爾蒙長期偏高，會影響脂肪代謝。【待營養師確認】
三、壓力和睡眠。睡不夠、壓力大，身體會把能量留下來。【待營養師確認】

秤重焦慮本身就是壓力。你越算越焦慮，越焦慮越難瘦。因人而異。

這就是為什麼放縱減肥法不算熱量。
它調的是比例和節奏。【待營養師確認】
比例對了，不用算也能往下走。

官網 FAQ 第四題就是這一題：熱量算對了還是瘦不下來？

留言「不算熱量」，我拍一支怎麼不算熱量也能瘦。
