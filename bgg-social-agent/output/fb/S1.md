# S1｜中秋烤肉先吃這三樣，隔天不腫｜fb

中秋烤肉不是不能吃，是你的順序吃錯了。

每年烤完隔天照鏡子，小腹又多一圈。很多人的反應是「那今年少吃一點」。結果撐到一半破功，反而吃更多。

放縱減肥法的比例原則，搬到烤肉架上就是三輪順序。

第一輪先吃蔬菜：青椒、香菇、玉米筍、絲瓜。
第二輪吃蛋白質：雞腿、蝦、豆干、魚。
第三輪澱粉吃飽：吐司、玉米、地瓜。【待營養師確認】

醬料刷一次，不回沾。【待營養師確認】
香腸、培根、貢丸可以吃，但它們是配角，不是主角。【待營養師確認】

照這個順序吃，隔天比較不腫。因人而異。

這個結構跟官網〈吃火鍋會胖嗎〉的四階段進食策略是同一套，只是把火鍋換成烤肉架。不是「不能吃」，是「先後順序」。

烤肉那天會用到。
