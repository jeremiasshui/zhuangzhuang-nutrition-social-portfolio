# S8｜三餐都外食的人，一天怎麼排？看一次就懂｜fb
回合：1
本輪修改：初稿
主要人物：P5
參考案例：待補
文案手法：待補

早餐超商、午餐便當、晚餐聚餐，這樣也能瘦？可以。

三餐都外食的人，最常問的是：我根本沒辦法自己煮，是不是就沒救了？
不是。差別只在比例。

示意架構，一天長這樣。實際比例依體質調整。

早餐｜超商
茶葉蛋、無糖豆漿，再加地瓜或御飯糰。蛋白質先有，澱粉照給。【待營養師確認】

午餐｜便當
飯吃飽，配兩份菜，主菜選不裹粉的。【待營養師確認】

晚餐｜聚餐
用烤肉那篇的順序：先蔬菜、再蛋白質、最後澱粉吃飽。【待營養師確認】

三餐都有解法。你不用換工作、不用帶便當、不用餐餐水煮。
餐餐吃超飽，也能往下走。因人而異。

再說一次：這是示意架構，實際比例要看你的體質和作息。
